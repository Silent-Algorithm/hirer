Hirer is a mobile-first social marketplace that connects people with nearby blue-collar workers such as plumbers, electricians, carpenters, and repair technicians. It is built for regions where hiring skilled labor is traditionally dependent on word of mouth, making it difficult for users to quickly find trusted help when they need it.

The app combines a social media feed with a service discovery platform. Users can create a single account to both post content and offer services. The home feed works like a social platform, showing a mix of normal posts and service listings from nearby users, ranked by location.

Hirer includes a search system to find workers by skill or name, a favorites system to save trusted profiles, and detailed user profiles that display skills, availability, ratings, location, and past posts. Each profile includes a direct WhatsApp contact button for quick communication and negotiation outside the app.

The goal of Hirer is to remove the dependency on personal connections for finding reliable local services, making skilled labor more accessible, transparent, and location-based.

Key features:

Social media style feed with service listings
Location-based discovery of nearby workers
Skill-based search system
User profiles with ratings, availability, and verification badge
Favorites system for saving trusted workers
WhatsApp-based direct contact for hiring
Single unified account system for all users

Hirer is designed to be simple, fast, and lightweight, optimized for mobile users in developing regions.
